# SpaceGray Light (Yazi flavor)

SpaceGray Light / Base16 Ocean Light - the light counterpart

Ported from the Base16 palettes of
<https://github.com/SublimeText/Spacegray> (MIT License).

## Usage

Enable it in theme.toml:

    [flavor]
    dark  = "spacegray-light"
    light = "spacegray-light"

Yazi has no CLI switch for flavors, so theme.toml is the only switch.

The bundled tmtheme.xml drives syntax highlighting inside the preview pane.
